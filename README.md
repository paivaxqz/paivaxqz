## 💼 Projetos em Destaque

### 🤖 Bot de Análises - Free Fire
Sistema completo e profissional de gerenciamento de análises de apostas para Discord.

**Características:**
- ✅ Sistema de permissões inteligente por cargo (EMU/MOB)
- ✅ Notificações automáticas via DM para analistas
- ✅ Interface minimalista com botões interativos persistentes
- ✅ Detecção automática de canais de análise
- ✅ Sistema de logs integrado e simplificado
- ✅ Gerenciamento de múltiplas análises simultâneas
- ✅ Views persistentes (funcionam após reiniciar)

**Tecnologias:** Python, Discord.py, AsyncIO, JSON

**Status:** ✅ Completo e em produção
